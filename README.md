# Lap One

ブラウザで動く3Dレースゲームです。インストール不要で、スマートフォン・タブレットでも遊べることを主な対象にしています。コインを使って車をカスタマイズし、天候の変わるコースでCPUと競います。

## 遊び方

### 基本の流れ

1. **初回レース**: 運営会社が最低性能の車を支給します。参加費はかかりません。
2. **2戦目以降**: 参加費 **1000 coin** を払ってレースに出ます。コインが足りないと出走できません。
3. **結果による精算**

| 結果 | 受け取り | 収支 (参加費1000の場合) |
|---|---|---|
| 優勝 | 賞金 3000 × コース倍率 | 倍率1.0なら +2000 |
| 完走 (未優勝) | 参加賞 500 | -500 |
| 失格 (大破) | なし | -1000 |

コース倍率は 1.0 / 1.2 / 1.5 の3段階です。難しいコースほど賞金が高くなります。

### コース

| コース | 難易度 | 賞金倍率 | 出やすい天候 |
|---|---|---|---|
| ゆるやかな楕円 | 初級 | ×1.0 | 晴れ、曇り、雨 |
| テクニカルサーキット | 中級 | ×1.2 | 曇り、雨、嵐 |
| 高速ヘアピン | 上級 | ×1.5 | 晴れ、霧、雨 |

全コース2周です。

### 天候

| 天候 | グリップ | 制動 | 特徴 |
|---|---|---|---|
| 晴れ | 100% | 100% | 基準 |
| 曇り | 98% | 100% | ほぼ基準 |
| 雨 | 80% | 85% | 雨用タイヤが効く |
| 嵐 | 65% | 75% | 横風で車が流される |
| 霧 | 100% | 100% | 視界が悪い。視界パーツで改善 |

### 損傷と失格

- 壁に当たる、他の車とぶつかる、コース外の壁にはみ出すと耐久が減ります。
- 耐久が0になると**失格**です。その場で退場し、参加賞はもらえません。参加費も戻りません。
- 耐久は次のレース開始時に全快します。
- フレームのパーツを良くすると、耐久の上限が上がります。

### ショップとガレージ

コインでパーツを買い、装着して性能を変えます。装着中の組み合わせで性能が決まり、ガレージ画面で合計値を確認できます。

| スロット | 主な効果 |
|---|---|
| エンジン | 最高速、加速 |
| フレーム | 耐久、旋回 |
| シャシ | 旋回、グリップ |
| ターボ | 加速 |
| マフラー | 最高速 |
| タイヤ | グリップ、雨天グリップ |
| ブレーキパッド | 制動 |
| シート | 旋回、グリップ |
| ハンドル | 旋回 |
| 窓 | 視界 |

各スロットは3段階 (標準、上位、最上位) です。

## 操作

### キーボード

| キー | 動作 |
|---|---|
| ← → / A D | ハンドル |
| ↑ / W | アクセル |
| ↓ / S | ブレーキ |
| C | 視点切替 (三人称 / 一人称) |

### タッチ (スマートフォン・タブレット)

- 左下の ◀ ▶ でハンドルを切ります。
- 右下の アクセル と ブレーキ を押して加減速します。
- 右上の 視点 ボタンで視点を切り替えます。

横向きでの利用を想定しています。

## 開発

### 必要なもの

- Node.js (v20 以降を推奨)
- npm

### セットアップと実行

```bash
npm install
npm run dev      # 開発サーバー (同じネットワークの端末からも開けます)
```

### ビルドとテスト

```bash
npm run build    # 型チェックと本番ビルド (dist/ に出力)
npm run preview  # ビルド結果の確認
npm test         # テスト (Vitest)
```

GitHub Pages などのサブディレクトリで公開する場合は、ビルド時に公開パスを指定します。

```bash
LAP_ONE_BASE=/Lap-One/ npm run build
```

### 構成

```
index.html            画面のスタイルとエントリ
src/
  main.ts             画面の流れ、レース開始と終了、ゲームループ
  game/
    courses.ts        コース定義 (制御点、幅、周回数、賞金倍率、天候の重み)
    track.ts          中心線の生成、AI の目標速度、最寄りのサンプル検索
    car.ts            車の1フレーム分の物理、周回の進捗
    race.ts           レース状態、CPU の運転、衝突、順位、失格
    parts.ts          パーツ定義と性能の合算
    economy.ts        参加費と賞金の計算
    weather.ts        天候の効果と抽選
    save.ts           セーブと設定 (localStorage)
    physics.ts        走行の基準値
    fixedStep.ts      固定タイムステップのループ
  render/scene.ts     three.js による描画 (コース、車、雨、カメラ)
  input/input.ts      キーボードとタッチの入力
  ui/ui.ts            メニュー、ガレージ、HUD、リザルトの画面
tests/                経済とレースのテスト
```

### セーブデータ

進行状況はブラウザの localStorage に保存されます。端末やブラウザを変えると引き継がれません。データを消すと、初期状態 (所持 1000 coin、標準パーツのみ) から始まります。
